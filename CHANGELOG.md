# Changelog

## v1.0.0 — Developer Pro release candidate (2026-10-12)
- Stable API/output version sourced from `version.py` for GUI, CLI, JSON/TXT/HTML, GitHub import user agent.
- Windows portable onedir builder with checks, ZIP packager and SHA-256 checksum.
- Windows + Linux CI testing, Windows CI binary packaging, version/tag gate and guarded GitHub Releases publishing.
- Updated end-user documentation, security policy, contributing guidelines, and release acceptance checklist.
- Preserved v0.9.1 Developer Pro UI, approved logo, local history, RU/EN and diagnostic engine.
- Not published or certified as a tested standalone executable until clean-Windows QA passes.
