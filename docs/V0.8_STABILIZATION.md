# RepoMedic v0.8 — stabilization checklist

**v0.8 focus: reliability, security review, reproducible builds and QA. No big redesign yet.**

## Release gates

- [ ] All existing automated tests pass on Windows 11 (Python 3.15 from the user's machine) and a supported Linux Python version (3.13 or later).
- [ ] Add a regression test for every newly discovered crash or false positive.
- [ ] Manual scan of Python, Node, Docker, multi-stage Docker, Compose and mixed real-world public repositories. Record exact repo revision and expected/observed findings.
- [ ] Check GitHub import: valid public URL, invalid URL, redirects, 404/403/rate limit, offline, oversized archive, malformed ZIP. Verify temp cleanup even after failure.
- [ ] Review report privacy: secrets not printed; local paths are documented; HTML escapes user-controlled values; symlink traversal rejected.
- [ ] Test CLI exit codes 0, 1 and 2 and all TXT/JSON/HTML exports. Confirm no project content changes during scans.
- [ ] Profile memory, time and UI responsiveness with small, medium and large bounded projects.
- [ ] Review all documented false positives and limitations of text-only Docker/Compose/Actions checks.
- [ ] Prepare reproducible Windows `.exe` build and clean VM smoke test, and draft Linux packaging strategy.
- [ ] Verify MIT license, correct README/setup instructions, CHANGELOG, code signing/distribution expectations, and no `.venv`, reports or secrets in release ZIP.

## Manual acceptance tests

| Case | Expected |
| --- | --- |
| Python project with valid pinned requirements and matching `.venv` | No dependency mismatch |
| Python with impossible exact version pins | Error with guidance |
| Pure Node.js project | No incorrect Python-venv requirement |
| Public GitHub ZIP | No local-venv/node_modules false alarm; bounded download |
| Dockerfile `FROM alpine:latest`, no USER | Two warnings and safe guidance |
| Compose `privileged: true` / `docker.sock` | Warnings, no Docker execution |
| GitHub workflow with `permissions: write-all` | Warning, no workflow execution |
| Invalid UTF-8 or oversized configuration | SKIP/ERROR without application crash |
| Scan 2 times in a row; switch directories | Correct report, no stale result |
| Save HTML/TXT/JSON on Windows | Correct text and escaped HTML |

After **v0.8** is stable, **v0.9** remains the major visual/UX redesign and public beta. **v1.0** remains the tested stable release.
